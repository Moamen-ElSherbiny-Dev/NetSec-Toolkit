<h2 align="left">📖 Introduction</h2>

###

<p align="left">NetSec Toolkit is a Python-based cybersecurity toolkit designed to provide a collection of practical network security and monitoring utilities within a single graphical interface.<br><br>The project combines multiple security modules, including packet filtering, network monitoring, port scanning, and application connection control, to provide users with a centralized environment for performing common network security tasks using Python and Windows Command Prompt (CMD).<br><br>The toolkit was developed as a practical cybersecurity project with a focus on network visibility, traffic control, security analysis, and user-friendly interaction.</p>

###

---

<h2 align="left">🔍 Overview</h2>

###

<p align="left">NetSec Toolkit provides several network security capabilities through an integrated graphical user interface for Windows.<br><br>The toolkit is designed to help users monitor network activity, inspect connected devices, scan available services, control application network connections, and apply packet filtering rules.<br><br>Each module focuses on a specific aspect of network security while working together as part of a unified security toolkit.</p>

###

---

<h2 align="left">🎯 Objectives</h2>

###

<p align="left"><b>The main objectives of this university project were:</b><br><br>
  ✅ Simplify firewall management and rule configuration for users.<br>
  ✅ Provide continuous, real-time network monitoring and visibility.<br>
  ✅ Improve network awareness by displaying active connection and devices.<br>
  ✅ Detect and analyze open ports and services running on network devices.<br>
  ✅ Implement protection mechanisms against common attacks, including distributed denial-of-service (DDoS) attacks.</p>

<h2 align="left">⚙️ System Architecture</h2>

###

<p align="left">The project consists of several software components integrated into a single graphical application.</p>

<p align="left"> <b>🖥️ Programming & Frameworks</b><br>

- Python for developing the core functionality of the toolkit.<br>
- CustomTkinter for building the graphical user interface.<br>
- Scapy for packet capture, network analysis, and packet filtering operations.<br>
- Nmap-based functionality for port and service scanning.<br><br>

<b>🔐 Security Modules</b><br>

- Packet Filtering<br>
- Live Network Monitoring & IP-ARP<br>
- Port Scanner<br>
- Application Connection Control<br>
- Systmes Logs<br>
</p>

---

<h2 align="left">🧩 Main Modules</h2>

###

<p align="left">

<b>🔥 Packet Filtering</b><br>
Provides packet filtering capabilities for controlling and analyzing network traffic. The module can monitor packets and apply filtering rules based on predefined conditions.<br><br>

<b>📡 Live Network Monitoring & IP-MAC Discovery</b><br>
Provides real-time visibility into network activity and connected devices. The module includes IP and ARP scanning functionality to help identify devices and network information.<br><br>

<b>🔎 Port Scanner</b><br>
Allows users to scan target hosts for open ports and identify available network services for security analysis.<br><br>

<b>🚫 App Connection Control</b><br>
Provides functionality for controlling application network connections and managing which applications are allowed to communicate over the network.<br><br>

<b>📋 System Logs</b><br>
Maintains security-related activity records to assist with monitoring, troubleshooting, and reviewing events generated by the toolkit.

</p>

<h2 align="left">🧪 Methodology</h2>

###

<p align="left"><b>The project was developed through several stages:</b><br><br> 1. Designing the overall toolkit architecture and defining the required security modules.<br> 2. Developing each network security module independently using Python.<br> 3. Implementing network packet analysis and filtering functionality using Scapy.<br> 4. Developing network monitoring and IP/ARP scanning capabilities.<br> 5. Implementing port and service scanning functionality.<br> 6. Developing application connection control mechanisms.<br> 7. Integrating all modules into a unified CustomTkinter graphical interface.<br> 8. Testing the toolkit under different network conditions and scenarios.<br> 9. Packaging the final application into a standalone executable using PyInstaller.</p>
